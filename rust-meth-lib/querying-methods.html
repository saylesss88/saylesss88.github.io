rust-meth-lib

Querying Methods

Shows how to work with the richer fields on [Method] beyond just the name:

  • Method::detail: the full function signature as a string (e.g. "const fn(&self) -> *mut T"), returned by rust-analyzer as the completion item’s detail field. Option<String>: not always present, especially for trait-provided methods on generic types.
  • Method::documentation: the rustdoc string for the method, often multi-line. Option<String>: coverage varies by crate and method.

Both fields are None when rust-analyzer doesn’t return them. Methods with neither still appear in the results from query_methods. This example filters to only those with at least one field populated, and renders them gracefully when the other is absent.

method_info.rs

use rust_meth_lib::analyzer::{Method, find_rust_analyzer, query_methods};

fn main() -> rust_meth_lib::error::Result<()> {
    let ra_path = find_rust_analyzer()?;

    let methods = query_methods("Cell<u8>", &ra_path, None)?;

    // Only print methods that have at least a signature. Methods with
    // neither detail nor docs still exist in the list, they're just
    // less useful for display purposes.
    let documented: Vec<&Method> = methods
        .iter()
        .filter(|m| m.detail.is_some() || m.documentation.is_some())
        .collect();

    println!(
        "{} of {} Cell<u8> methods have signatures or docs:\n",
        documented.len(),
        methods.len()
    );

    for method in documented {
        // The signature line (e.g. "pub fn push_str(&mut self, string: &str)")
        if let Some(sig) = &method.detail {
            println!("fn {}  →  {sig}", method.name);
        } else {
            println!("fn {} (no signature)", method.name);
        }

        // Rustdoc
        if let Some(doc) = &method.documentation {
            // Just the first sentence to keep output manageable.
            let first_line = doc.lines().next().unwrap_or("").trim();
            if !first_line.is_empty() {
                println!("  doc: {first_line}");
            }
        }

        println!();
    }

    Ok(())
}
